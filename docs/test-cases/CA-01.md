# Test cases - CA-01: Cont, intrare, deconectare, nume și salut

User Story: Ca utilizator, vreau un cont al meu - să-l creez cu emailul și o parolă, să intru în el, să mă deconectez și să fiu salutat pe nume - ca să am cheltuielile salvate în siguranță și să nu le vadă altcineva.

Abordare de dezvoltare: tradițională.

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă în Expo Go.
3. Confirmarea emailului (până la finalizarea CA-02): `cd server` și `npm run db:studio`, apoi în tabela `user` se setează `emailVerified` = `true` pentru contul de test.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
