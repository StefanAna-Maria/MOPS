# Test cases - CA-02 (partea 1): Confirmarea emailului cu un cod

Rămâne pentru mai târziu: trimiterea unui email real (acum codul se citește din log).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`. Fără `RESEND_API_KEY` emailul nu se trimite, iar codul apare în log: `[email-otp] email-verification <email>: <cod>`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă în Expo Go.

## Resetarea parolei (CA-02.11 - CA-02.14)

Pregătire: cod în log-ul serverului (`[email-otp] forget-password <email>: <cod>`), un cont confirmat.

| ID | Criteriu | Tip | Pași | Rezultat așteptat | Test automat |
|---|---|---|---|---|---|
| TC-02.11 | CA-02.11 | automat + manual | „Intră în cont” → „Ai uitat parola?”, se scrie emailul contului și se apasă „Trimite codul”. | Se deschide „Parolă nouă” cu „Am trimis un cod de 6 cifre la {email}.”; se „trimite” emailul „Resetează-ți parola” cu codul (în log); în tabela `verification` codul e doar hash. | `server/tests/reset-password.test.ts`, `mobile/tests/forgot-password.test.tsx`, `mobile/tests/reset-password.test.tsx` |
| TC-02.12 | CA-02.12 | automat + manual | Se scrie codul corect și o parolă nouă validă, apoi „Schimbă parola”. | Parola se schimbă și intri automat în aplicație; vechea parolă nu mai merge. Cod greșit: „Cod greșit”; cod expirat: „Codul a expirat”; parolă slabă: 400 `PASSWORD_TOO_WEAK` fără ca codul să fie consumat; un cod merge o singură dată. | `server/tests/reset-password.test.ts`, `mobile/tests/reset-password.test.tsx` |
| TC-02.13 | CA-02.13 | automat + manual | Se cere resetarea pentru un email fără cont. | Același răspuns (200 `{ success: true }`) și același ecran ca pentru un cont existent; nu se trimite niciun email și nu se creează niciun cod în baza de date. | `server/tests/reset-password.test.ts`, `mobile/tests/forgot-password.test.tsx` |
| TC-02.14 | CA-02.14 | automat + manual | Cu contul intrat pe două dispozitive, se resetează parola pe unul. | Toate sesiunile vechi ale contului se închid (401 la `GET /api/me`, rândurile dispar din tabela `session`); dispozitivul care a resetat intră cu noua parolă. | `server/tests/reset-password.test.ts` |
