# Test cases - CA-02 (partea 1): Confirmarea emailului cu un cod

Rămân de făcut în CA-02: sesiunea păstrată (CA-02.8–10) și resetarea parolei (CA-02.11–14).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`. Fără `RESEND_API_KEY` emailul nu se trimite, iar codul apare în log: `[email-otp] email-verification <email>: <cod>`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă în Expo Go.
