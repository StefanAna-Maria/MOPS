# Test cases - CA-03: Adăugarea unei cheltuieli manuale

User Story: Ca utilizator, vreau să notez o plată pentru care nu am bon, ca să apară și ea în cheltuielile mele.

Abordare de dezvoltare: tradițională.

## Pregătire pentru verificarea manuală

1. Migrarea aplicată: `cd server` și `npm run db:migrate` (creează tabelele `document` și `document_line`).
2. Serverul pornit: `cd server` și `npm run dev`.
3. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă în Expo Go, cu un cont confirmat.
4. Pe Acasă: „Adaugă o cheltuială”. Cheltuielile salvate se văd în `npm run db:studio` (tabelele `document`, `document_line`) până la finalizarea US-04 (lista pe Acasă).

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
