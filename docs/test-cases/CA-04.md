# Test cases - CA-04: Lista cheltuielilor lunii pe Acasă

User Story: Ca utilizator, vreau să-mi văd cheltuielile lunii grupate pe zile, ca să știu ce am cheltuit și când.

Abordare de dezvoltare: tradițională.

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă în Expo Go, cu un cont confirmat.
3. Câteva cheltuieli adăugate cu „Adaugă o cheltuială” (US-03), cu date diferite din luna curentă (azi, ieri, mai devreme) și una din luna trecută.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
