# Test cases - CA-05: Totalul lunii și variația față de luna trecută

User Story: Ca utilizator, vreau să văd cât am cheltuit luna aceasta față de luna trecută, ca să știu dacă stau bine.

Abordare de dezvoltare: tradițională (implementare, apoi teste).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă pe un telefon în Expo Go, cu un cont confirmat.
3. Cheltuieli adăugate în luna curentă (din mai multe categorii) și, pentru verificarea variației, cel puțin o cheltuială cu data în luna trecută.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
