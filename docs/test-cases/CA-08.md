# Test cases - CA-08: Fotografierea unui document cu camera

User Story: Ca utilizator, vreau să fotografiez un bon cu camera aplicației, ca să nu-l mai păstrez pe hârtie.

Abordare de dezvoltare: AI-assisted (Antigravity).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă pe un dispozitiv fizic în Expo Go.
3. Autentificare în aplicație pe ecranul Acasă.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
