# Test cases - CA-10: Progresul și erorile citirii automate

User Story: Ca utilizator, vreau să văd cum avansează citirea bonului și ce pot face dacă nu merge, ca să nu aștept fără să știu ce se întâmplă.

Abordare de dezvoltare: AI-assisted (Antigravity).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Serviciul OCR (llama.cpp cu Qwen3-VL) pornit conform `docs/SETUP.md`.
3. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă în Expo Go, autentificată pe ecranul Acasă.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```

## Test cases

| ID | Criteriu | Tip | Pași | Rezultat așteptat | Test automat |
|---|---|---|---|---|---|
| TC-10.1 | CA-10.1 | automat + manual | Se fotografiază un bon pe ecranul `/scan`, se apasă „Continuă” și se urmărește ecranul de citire (`/scan-result/[id]`). | Cât timp se încarcă și se citește documentul, sunt vizibile și avansează în ordine etapele reale: „Încărcăm documentul”, „Citim documentul”, „Găsim magazinul, data și totalul”, „Extragem produsele”. | `mobile/tests/scan-result.test.tsx`, `server/tests/scans.test.ts` |
| TC-10.2 | CA-10.1 | automat | În timpul citirii, serverul raportează pe rând etapele `READING`, `EXTRACTING_FIELDS` și `EXTRACTING_ITEMS` prin `GET /api/scans/:id`. | Indicatorul activ din interfață avansează pe fiecare etapă, marcând etapele anterioare ca finalizate, până când statusul devine `DONE`. | `mobile/tests/scan-result.test.tsx`, `server/tests/scans.test.ts` |
| TC-10.3 | CA-10.2 | automat + manual | Se oprește serviciul OCR (`OCR_UNAVAILABLE`) sau citirea expiră (`OCR_TIMEOUT`) și se trimite o poză. | Ecranul afișează mesajul „Documentul nu a putut fi citit.” împreună cu motivul și butonul „Încearcă din nou” (precum și opțiunea „Fotografiază din nou”). | `mobile/tests/scan-result.test.tsx`, `server/tests/scans.test.ts`, `server/tests/ocr-client.test.ts` |
| TC-10.4 | CA-10.2 | automat + manual | Se trimite o fotografie ilizibilă / care nu conține un bon (`UNREADABLE`). | Ecranul afișează „Documentul nu a putut fi citit.” cu explicația și butonul „Încearcă din nou”. | `mobile/tests/scan-result.test.tsx`, `server/tests/scans.test.ts` |
| TC-10.5 | CA-10.2 | automat + manual | După o eroare `OCR_UNAVAILABLE`, se repornește serviciul OCR și se apasă „Încearcă din nou”. | Aplicația apelează `POST /api/scans/:id/retry`, reia afișarea etapelor de citire și afișează datele extrase după finalizare. | `mobile/tests/scan-result.test.tsx`, `mobile/tests/scan-upload.test.ts`, `server/tests/scans.test.ts` |
