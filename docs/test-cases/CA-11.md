# Test cases - CA-11: Verificarea datelor citite și salvarea documentului

User Story: Ca utilizator, vreau să corectez doar valorile nesigure și să știu că totalul se potrivește, ca să salvez un document corect.

Abordare de dezvoltare: TDD (Red → Green pentru `shared`, server și aplicație, vizibil în istoricul repository-ului).

## Pregătire pentru verificarea manuală

1. Migrarea aplicată: `cd server` și `npx prisma migrate deploy` (coloana `fileId` din tabela `document`, legătura cu poza).
2. Serverul pornit: `cd server` și `npm run dev`.
3. Microserviciul OCR pornit (llama.cpp cu Qwen3-VL 4B, pe `http://127.0.0.1:8080`), ca la CA-09.
4. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă pe un telefon în Expo Go, cu un cont confirmat.
5. Pe Acasă se fotografiază un bon (sau se importă din galerie) și se apasă „Continuă”; după citire se deschide ecranul de verificare.

## Rularea testelor automate

Din rădăcina repository-ului (testele nu au nevoie de microserviciul OCR):

```bash
npm test
npm run test:coverage
```
