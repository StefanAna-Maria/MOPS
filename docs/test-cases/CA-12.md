# Test cases - CA-12: Ștergerea contului

User Story: Ca utilizator, vreau să-mi șterg contul cu tot ce conține, ca să nu rămână date despre mine.

Abordare de dezvoltare: tradițională (implementare, apoi teste).

## Cum funcționează

- În „Contul meu” (cercul cu inițiale), sub „Deconectează-te”, apare „Șterge contul”.
- Apare întrebarea „Ștergi contul?” cu „Șterge definitiv” și „Renunță”.
- La confirmare, aplicația trimite `DELETE /api/me`. Serverul șterge contul, parola, sesiunile, profilul, firma, documentele cu produsele, înregistrările fișierelor și citirile lor, categoriile proprii, codurile trimise pe email și pozele / PDF-urile de pe disc.
- Aplicația șterge apoi sesiunea de pe telefon și deschide „Intră în cont”.
- Rămân doar contoarele de limitare a cererilor (tabela `rateLimit`: adresă IP și rută), care nu sunt legate de cont, și copiile din istoricul bazei de date păstrate de furnizor (Neon).

## Pregătire pentru verificarea manuală

1. Serverul pornit (local: `cd server` și `npm run dev`) sau cel de pe Vercel.
2. Aplicația pornită: `cd mobile` și `npx expo start`.
3. Un **cont de test**, cu cel puțin o cheltuială. Ștergerea este definitivă.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
