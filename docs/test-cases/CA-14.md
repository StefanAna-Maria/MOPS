# Test cases - CA-14: Importul unei poze sau al unui PDF

User Story: Ca utilizator, vreau să adaug un document pe care îl am deja în telefon, ca să nu-l fotografiez din nou.

Abordare de dezvoltare: tradițională.

## Cum funcționează

- Pe ecranul camerei (Acasă → butonul cu cameră) există, lângă declanșator, „Din galerie” (stânga) și „Din fișiere” (dreapta). Ambele apar și când aplicația nu are acces la cameră.
- „Din galerie” deschide alegerea de poze a telefonului; „Din fișiere” deschide alegerea de fișiere și arată PDF-uri și imagini.
- Documentul ales nu mai trece prin previzualizare: se trimite imediat serverului și se deschide „Citim documentul” (aceeași citire ca pentru o poză făcută cu camera, US-09 și US-10).
- Pozele se micșorează la cel mult 2048 px pe latura lungă, ca pozele din cameră. Un PDF se trimite așa cum este; serverul desenează prima pagină ca imagine (PNG, 2048 px pe latura lungă) și o citește ca pe o poză. Se citește doar prima pagină.
- Limita rămâne 10 MB pe fișier.

## Pregătire pentru verificarea manuală

Ca la CA-09 (serverul, aplicația în Expo Go și microserviciul OCR pornite). Pe telefon trebuie să existe o poză în galerie, un PDF (un bon sau o factură) și un fișier care nu e nici poză, nici PDF (de exemplu un `.txt`) în „Fișiere”.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
