# Test cases - CA-15: Filtrarea documentelor după tip

User Story: Ca utilizator, vreau să văd doar un tip de documente, ca să găsesc repede o factură.

Abordare de dezvoltare: tradițională (implementare, apoi teste).

Notă: aplicația nu are chitanțe; echipa a hotărât filtrele „Toate”, „Bonuri”, „Facturi” și „Manuale” (cheltuielile adăugate manual, fără poză).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă pe un telefon în Expo Go, cu un cont confirmat.
3. În luna curentă există cel puțin un bon scanat, o factură scanată și o cheltuială adăugată manual.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
