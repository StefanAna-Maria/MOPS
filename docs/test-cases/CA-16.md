# Test cases - CA-16: Cheltuielile pe categorii în luna curentă

User Story: Ca utilizator, vreau să văd pe ce categorii s-au dus banii lunii, ca să știu unde să tai.

Abordare de dezvoltare: tradițională (implementare, apoi teste).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Aplicația pornită: `cd mobile` și `npx expo start`, deschisă pe un telefon în Expo Go, cu un cont confirmat.
3. Cheltuieli adăugate în luna curentă din mai multe categorii (inclusiv o categorie personalizată și un bon scanat cu produse din categorii diferite).

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```
