# Test cases - CA-17: Aplicația în limba utilizatorului

User Story: Ca utilizator, vreau aplicația în limba mea, ca să o înțeleg fără efort.

Abordare de dezvoltare: tradițională (implementare, apoi teste).

## Pregătire pentru verificarea manuală

1. Serverul pornit: `cd server` și `npm run dev`.
2. Aplicația pornită: `cd mobile` și `npx expo start --clear`, deschisă pe un telefon în Expo Go, cu un cont confirmat.
3. Limba se schimbă din: cercul cu inițiale (dreapta sus pe Acasă), care deschide „Contul meu” → „Limba”.

## Rularea testelor automate

Din rădăcina repository-ului:

```bash
npm test
npm run test:coverage
```

## Regula pentru textele noi

Toate textele aplicației sunt în `mobile/src/i18n/ro.ts` (română) și `mobile/src/i18n/en.ts` (engleză). Un text nou se adaugă în ambele fișiere și se folosește în ecran cu `const t = useT();` (de exemplu `t.home.addExpense`). Dacă textul englez lipsește, proiectul nu compilează; dacă un text românesc este scris direct într-un ecran, pică testul `mobile/tests/no-hardcoded-texts.test.ts`.
